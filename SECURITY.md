# Security Policy

## Supported Versions

This is a school/learning project (42 Inception). Only the `main` branch is
maintained.

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

If you find a security issue (e.g. exposed secrets handling, container
misconfiguration, outdated base images with known CVEs):

1. Do **not** open a public issue with exploit details.
2. Contact the maintainer directly via the email on the GitHub profile, or
   open a [private security advisory](../../security/advisories/new) on this
   repository.
3. Include a description of the issue, steps to reproduce, and potential
   impact.

Reports will be acknowledged within a few days. Since this is a personal
learning project rather than production software, fixes are best-effort.
